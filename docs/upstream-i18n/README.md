# 上游多语言文档（留档，与本项目无关）

这 60 份文件是从 RustDesk 上游 `docs/` 目录搬过来的翻译文档：

- `README-*.md` —— 上游 README 的 33 种语言版本
- `CONTRIBUTING-*.md` —— 上游贡献指南的翻译
- `CODE_OF_CONDUCT-*.md` —— 上游行为准则的翻译
- `SECURITY-*.md` —— 上游安全策略的翻译

**为什么搬到这里而不是删掉**：

它们是 vendored 上游源码的一部分，删了会让"本仓库包含上游完整源码"这一点不完整
（AGPL-3.0 要求分发时提供完整源码）。但放在 `docs/` 根目录会淹没我们自己的文档，
所以收进这个子目录，并在 `docs/README.md` 里明确标注"与本项目无关"。

**不要读这些文档来操作本项目** —— 里面讲的是如何给 RustDesk 官方贡献代码、
如何连接官方服务器，与我们的私有化定制**完全无关**。

本项目的文档在上级目录：`../01-architecture.md` 等，索引入口是 `../README.md`。
